# lezreg 0.2.0

## New
- `lezreg show` prints each entry's IDL status (ok, unknown format, unavailable, hash mismatch, parse error) next to its metadata, in text and JSON. A failed IDL never hides the entry. `idl get` still exits non-zero when the IDL is unavailable.
- IDL tools that need no chain: `lezreg idl encode|decode` (messages, actor state, events; SPEL v1, SPEL v2 and v1 + x-lez04), `lezreg call --plan` (message bytes, actors to declare, signers; sends nothing; not a simulation), `lezreg image-id <elf|bin> [--compare HEX]`.
- `lezreg_sdk::idl_codec`: encode and decode any registered program's messages, state and events from its IDL.
- `idl/lez_program_registry.v2.json`: a SPEL v2 twin of the registry IDL, tested to describe the same bytes as the generated v1 file (hand-written, not generated from source).
- Network files: `--network testnet` reads an embedded v2 network file (today this project's rc3 test network, lez.nameswallet.app); `LEZREG_NETWORK_FILE` / `network set --network-file`, `--chain-id`, `--lns`; `network show --check-chain` compares the chain id with the sequencer's `getChannelId`.
- `verify` and `build` disclose the third-party services they use (Docker Hub, crates.io, the git forge) in `--help`, on stderr and in JSON, and take local inputs instead: `--image-tar`, `--vendor-tar`, `--archive-file`, `--no-forge`, `--offline`. The offline path is unit-tested; it has not been run end to end with Docker yet.
- JS SDK: `byAuthor`, `thirdParty`, IDL statuses with Rust's names (`statusKind`), and write bytes for register, third-party register and update (`sdk/js/writes.js`), checked byte for byte against Rust. Signing needs a signer you pass in; the SDK holds no keys.
- LNS: records up to version 7 are read, so `lezreg app show|get|verify` work for names that carry an NFT deed; the app commands use the network's LNS program unless `--lns` is given.
- Basecamp module (source; catalog release separate): app checks recompute the package root from its files (`Contents::from_installed` / `from_lgx` + `Names::verify`) and read deeded (version 7) LNS names; defaults come from the embedded network file; a sequencer URL no longer selects an LNS program.

## Changed
- `testnet` is no longer a placeholder that refuses: it points at the network file's sequencer. Logos LEZ testnet 0.4 has still not launched.
- The installer's previous release (0.1.0) lacks all of the above.
- The registry program is unchanged: same image id (`artifacts/lez_program_registry.imageid`). Only the tools' version moved to 0.2.0; the crates built into the program keep version 0.1.0, so its reproducible build is expected to give the same image id (`repro.yml` checks it against the committed one).

## Not in this release
- Generating a LEZ/SPEL v2 IDL from source, simulating a third-party call, a generic send.
- JS transfer/freeze builders.
